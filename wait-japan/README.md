# WAIT, JAPAN?

Questions about Japan you never thought to ask.

## Production principle
Automate the production process, not the substance. Each episode must have its own researched question, verified fact sheet, source registry, narrative structure, and original visual plan.

## Episode 001
**Why Does Japan Have So Few Trash Cans — Yet Stay So Clean?**

Status: research/fact-check/script/storyboard complete; final visuals, final voice, render and upload pending.

## Series structure
Long-form episodes are the source material. Each long-form episode produces three Shorts with different hooks rather than three near-identical cuts.

## Monetization guardrail
The system may reuse brand elements, intro/outro, typography and rendering code, but not interchangeable scripts or generic image slideshows. Every episode must deliver materially different educational content and narrative value.
