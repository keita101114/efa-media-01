This Privacy Policy explains how WAIT JAPAN Content Automation ("the Tool") accesses, uses, stores, and protects information when using YouTube API Services.

1. Use of YouTube API Services

The Tool uses YouTube API Services. Use of the Tool is also subject to Google's privacy practices. Please review the Google Privacy Policy.

2. Information accessed

After the channel owner authorizes access through Google OAuth 2.0, the Tool may access data necessary to operate creator-managed publishing workflows, including:

  • YouTube channel identifiers and channel titles;
  • video identifiers;
  • video metadata such as titles, descriptions, tags, thumbnails, visibility status, and publication schedule;
  • video processing or upload status; and
  • OAuth authorization credentials required to make authorized API requests.

The Tool does not request, collect, or store the user's Google or YouTube account password.

3. How information is used

Information is used only to perform actions requested or approved by the channel owner, including uploading videos, managing metadata and thumbnails, checking processing status, verifying the target channel, and managing publication settings.

Information is not sold, rented, used for advertising profiles, or shared with unrelated third parties.

4. Storage and security

The Tool is an internal command-line application. OAuth authorization credentials and limited workflow state may be stored locally on the operator's controlled device and are not published on this website. Reasonable technical safeguards are used to prevent unauthorized access.

YouTube API data is retained only as needed for the authorized workflow and is refreshed or deleted when it is no longer required, subject to applicable YouTube API Services policies.

5. Revoking access

The channel owner may revoke the Tool's access at any time through the Google security permissions page.

When authorization is revoked, stored Authorized Data associated with that authorization will be deleted as soon as reasonably possible and no later than the period required by applicable YouTube API Services policies.

6. Data deletion requests

Because the Tool is currently used only by its owner, deletion requests are handled directly by the operator. A request to remove locally stored YouTube API data or authorization state may be sent to keitakikuchi1414@gmail.com.

Deleting data stored by the Tool does not delete data stored by YouTube. YouTube content must be deleted through YouTube or an authorized client that supports such deletion.

7. Third-party content and cookies

This website does not use advertising cookies or third-party advertising services. The Tool does not permit unrelated third parties to access Authorized Data.

8. Changes to this policy

This policy may be updated when the Tool's functionality or applicable platform requirements change. The current version will remain publicly available at this URL.
